===== Flask (port 5000) =====
$ curl localhost:5000/
Student Management API [HTTP 200]
$ curl localhost:5000/students
[ { "branch": "CSE", "id": 1, "name": "Aarav" }, { "branch": "ECE", "id": 2, "name": "Diya" }, { "branch": "IT", "id": 3, "name": "Rohan" } ] [HTTP 200]
$ curl localhost:5000/students/1
{ "branch": "CSE", "id": 1, "name": "Aarav" } [HTTP 200]
$ curl localhost:5000/students/5
{ "error": "Student not found" } [HTTP 404]
$ curl -X POST localhost:5000/students -H "Content-Type: application/json" -d {"name":"Meera","branch":"IT"}
{ "branch": "IT", "id": 4, "name": "Meera" } [HTTP 201]
$ curl -X POST localhost:5000/students -d {}
{ "error": "name and branch are required" } [HTTP 400]
$ curl localhost:5000/students   (after POST)
[ { "branch": "CSE", "id": 1, "name": "Aarav" }, { "branch": "ECE", "id": 2, "name": "Diya" }, { "branch": "IT", "id": 3, "name": "Rohan" }, { "branch": "IT", "id": 4, "name": "Meera" } ]
